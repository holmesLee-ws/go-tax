# go-tax

한국 세무를 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 법인세, 부가가치세, 원천징수, 소득세, 지방세, 조세특례, 세무조사 대응, 국제조세를 다룹니다. 한국 법과 제도가 뼈대이고, OECD·UN 모델과 EU·미국·일본 제도는 비교 축으로 씁니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 세율이나 기한 같은 수치도 적어 두지 않았습니다. 세법은 해마다 바뀌므로, 튜터가 세션마다 국세청·국가법령정보센터 같은 공식 출처를 조회해 적용 연도와 함께 알려 줍니다. 도식과 표를 담은 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

> 여기는 세무를 배우는 곳이지 세무 자문을 받는 곳이 아닙니다. 실제 신고와 판단은 세무대리인이나 국세청 상담으로 확인하세요. 대화에 사업자등록번호, 주민등록번호, 실제 거래처나 금액을 넣지 마세요. 튜터는 예시 값으로 바꿔서 진행합니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-tax
```

**Claude Code**

```bash
cd ~/Desktop/go-tax
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-tax` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 세무 업무 경험은 어떤지 짧게 묻고, 영역마다 상황 문제를 하나씩 풀어 출발점을 찾습니다. 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 내 업무에 맞춘 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML(흐름도, 판단표, 체크리스트)을 만들어 가며 익힙니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 마지막에는 우리 회사에 쓸 실무 문서 초안(연간 세무 캘린더, 세무 위험 점검표, 세무조사 대응 체크리스트 중 하나)을 만듭니다.
6. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「표로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도(모듈마다 국내 근거·글로벌 비교, 공식 출처와 조회일) |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙. 출처 확인 규칙은 [tutor/sources.md](tutor/sources.md) |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록과 내 HTML. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

다른 경영 영역과 겹치는 주제(회계 처리, 비상장주식 평가, 급여 제도, 내부통제 등)는 지도에 「경계·연결」로 표시하고 깊게 다루지 않습니다.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록과 `learner/studio`의 HTML을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 민감한 정보는 대화에 넣지 마세요.
